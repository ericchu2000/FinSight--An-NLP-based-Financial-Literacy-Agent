# 金融教育模块输入和输出格式定义

本文档定义了针对股票预测对赌游戏中失败用户的金融教育内容输出格式。这些格式规范旨在确保内容既专业又易于理解，帮助用户学习相关金融知识。
## 输入格式

模型将接收上游股票预测模型的输出信息。输入格式可能会变化，但通常包含以下关键信息（具体字段名可能会根据上游模型输出而变化）：

### 必要信息

- **预测结果**：股票将上涨或下跌的结论
- **用户预测**：用户下注的预测方向
- **分析因素**：影响预测的各种因素，如技术指标、基本面数据等

### 可选信息

- **股票信息**：股票名称、代码、行业等
- **时间范围**：预测的时间周期
- **置信度**：模型对预测的信心程度
- **用户经验水平**：用户的金融知识背景

### 示例格式（仅供参考）

```json
{
  "prediction": {
    "result": "上涨",
    "confidence": 0.75,
    "timeframe": "一周"
  },
  "factors": [
    {
      "name": "MACD",
      "value": "金叉形成",
      "impact": "正面",
      "weight": 0.4
    },
    // 其他因素...
  ],
  "stock": {
    "name": "阿里巴巴",
    "code": "BABA",
    "industry": "电商"
  },
  "user": {
    "prediction": "下跌",
    "experience": "初级"
  }
}
```

### 输入适应能力

模型应能够适应不同的输入格式变化，例如：
- 字段名称可能不同，但表达相同含义
- 结构嵌套层级可能不同
- 部分字段可能缺失，需用其他信息补充

如果某些关键信息缺失，模型应专注于可以提取的部分，并依然提供有价值的教育内容。

## 整体结构

金融教育内容将按照以下结构呈现：

```
1. 预测结果解析
2. 核心决策因素
3. 金融知识讲解
   - 关键概念1
   - 关键概念2
   - ...
4. 投资启示
5. 延伸学习
```

## 详细格式规范

### 1. 预测结果解析

**目的**：帮助用户理解为什么AI的预测结果与用户预测不同

**格式要求**：
- 篇幅：50-80字
- 语气：客观中立，不带评判
- 内容要素：
  * AI的预测结果
  * 用户的预测结果
  * 实际结果简述
  * 影响结果的1-2个主要因素

**示例**：
```markdown
## 预测结果解析

在本次预测中，AI系统预测阿里巴巴股票在一周内会上涨，而你预测的是下跌。实际结果显示股票确实上涨了约3.5%，主要受技术指标改善和行业利好政策的推动。
```

### 2. 核心决策因素

**目的**：展示AI系统做出预测的主要依据，按重要性排序

**格式要求**：
- 呈现方式：有序列表（按重要性降序）
- 数量：3-5个关键因素
- 每个因素包含：
  * 因素名称（加粗显示）
  * 具体情况描述
  * 影响权重或重要性说明

**示例**：
```markdown
## 核心决策因素

1. **MACD指标金叉形成**：技术指标MACD出现金叉形态，这是一个强烈的上涨信号，在预测中占40%的权重
2. **RSI指标处于低位**：相对强弱指标RSI值为40，表明股票可能被超卖，有反弹空间，占30%权重
3. **行业利好政策**：近期发布的政策对电子商务行业有积极影响，占20%的权重
```

### 3. 金融知识讲解

**目的**：详细解释关键金融概念，帮助用户理解预测依据

**格式要求**：
- 结构：每个关键概念独立成段，使用三级标题
- 每个概念讲解包含三部分：
  * **概念定义**：简洁明了的定义（30-50字）
  * **实际应用**：在本次预测中的应用方式（40-60字）
  * **日常类比**：使用生活中的例子进行类比说明（50-80字）
- 语言要求：避免专业术语，或在使用时立即解释
- 概念数量：2-3个最关键的概念

**示例**：
```markdown
## 金融知识讲解

### MACD指标

**概念定义**：MACD是一种常用的技术分析工具，通过计算两条不同周期移动平均线之间的差值来判断股票价格趋势。

**实际应用**：在本次预测中，MACD指标出现了"金叉"形态（快线从下方穿过慢线），这通常被视为买入信号，预示着股价可能上涨。

**日常类比**：想象你在观察一条繁忙道路上的车流。短期移动平均线就像是观察10分钟内通过的车辆数量，长期移动平均线则是观察30分钟内的平均车流量。当短期车流量开始超过长期平均时（形成"金叉"），这通常意味着道路变得更加繁忙，类似于股票交易活动增加，价格可能上涨。
```

### 4. 投资启示

**目的**：从本次预测中提炼出实用的投资原则或技巧

**格式要求**：
- 呈现方式：无序列表
- 数量：2-3条启示
- 每条启示内容：
  * 简短标题（加粗）
  * 简明扼要的解释（40-60字）
- 语气：建议性而非指令性

**示例**：
```markdown
## 投资启示

- **技术指标组合分析**：单一指标可能产生误导，但多个指标共同指向同一方向时，信号可能更加可靠。
- **政策面影响**：行业政策对股票短期表现有显著影响，关注相关政策动向可以帮助判断股票走势。
- **市场情绪与基本面平衡**：虽然市场情绪略偏悲观，但当基本面和技术面都较为正面时，股票仍可能上涨。
```

### 5. 延伸学习

**目的**：引导用户进一步探索相关金融知识

**格式要求**：
- 呈现方式：1-2个建议主题，每个主题使用粗体
- 内容：每个主题包含简短描述（30-50字）
- 结尾：添加一个开放性问题，鼓励用户互动

**示例**：
```markdown
## 延伸学习

- **技术分析中的其他常用指标**：如果你想深入了解更多技术分析工具，可以探索布林带(Bollinger Bands)和移动平均线(Moving Average)等概念。
- **基本面分析入门**：了解如何通过公司财务数据、行业地位和增长前景等因素评估股票的内在价值。

有什么特定的金融概念你想进一步了解吗？
```

## 可视化元素指南

在适当的情况下，金融教育内容可以包含以下可视化元素：

### 1. 表格

用于比较不同指标或概念的特点，格式如下：

```markdown
| 指标名称 | 适用场景 | 使用注意点 |
|---------|---------|-----------|
| MACD    | 趋势判断 | 可能有滞后性 |
| RSI     | 超买超卖 | 震荡市中更有效 |
```

### 2. 图表描述

当需要描述图形趋势时，可使用文本模拟简单图表：

```markdown
MACD金叉形态示意：
    
    价格
    ^
    |          /
    |         /
    |    ____/
    |___/
    |
    +---------------> 时间
       ↑
      金叉形成点
```

### 3. 概念关系图

当解释多个相关概念时，可通过文本描述它们的关系：

```markdown
技术指标关系：
RSI(超买超卖信号) → 结合 → MACD(趋势确认) → 共同指向 → 买入/卖出决策
```

## 互动式学习建议

每个教育内容末尾应包含互动式学习元素：

### 1. 思考问题

提供1-2个开放性问题，鼓励用户应用所学知识：

```markdown
### 思考问题

- 根据今天学习的MACD指标，你认为什么情况下它可能会给出错误信号？
- 在做投资决策时，你会如何结合技术指标和基本面因素？
```

### 2. 应用建议

提供实践性建议，帮助用户巩固所学知识：

```markdown
### 应用建议

下次分析股票时，尝试同时观察MACD和RSI指标，看它们是否给出一致的信号，这可以帮助你更全面地理解市场状况。
```

### 3. 学习路径

为不同层次的用户提供进阶学习方向：

```markdown
### 进阶学习路径

- **初学者**：先了解更多基础技术指标的含义和使用方法
- **进阶者**：学习如何将多种技术指标组合使用，形成交易策略
- **高级者**：探索如何结合基本面分析和技术分析，进行更全面的投资决策
```

## 注意事项

1. **避免投资建议**：所有内容应以教育为目的，不提供具体投资建议
2. **清晰层次**：使用Markdown标题层级确保内容结构清晰
3. **语言适应**：根据用户水平调整专业术语使用频率和解释详细程度
4. **保持互动**：内容末尾总是留有开放性问题，鼓励用户进一步探讨
